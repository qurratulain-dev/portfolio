# Quratulain Naseem — Portfolio

Personal portfolio website built with React, Vite, Tailwind CSS, and GSAP.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Local development

```sh
npm ci
npm run dev
```

## Production

```sh
npm run build
npm run preview
```

Run the static checks with:

```sh
npm run lint
```

The production site is configured for root deployment (`base: "/"`). The canonical site URL and social metadata are defined in `index.html`.
